# Overview & Architecture

A precision-crafted UI component library built on Radix UI, Tailwind CSS, and hardware-accelerated canvas backgrounds — designed for mission-critical developer tools, terminals, and futuristic dashboards.

## Core Architectural Pillars

### Precision Aesthetics
Clean rectangular geometry, pitch-dark OLED contrast, and tactical sci-fi chamfers without unnecessary decoration.

### Radix UI Primitives
Fully keyboard accessible with ARIA semantics, focus management, and robust state machines.

### 60fps Canvas Backgrounds
Hardware-accelerated dynamic backgrounds (Constellations, Perlin Noise, Aurora) in 1 line of JSX.
